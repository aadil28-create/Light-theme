START PROJECT + DESIGN SYSTEM + APP STRUCTURE

Create a FRONTEND/UI DESIGN DONOR for an existing production real-time Live Quiz Platform.

IMPORTANT ARCHITECTURE RULE:

The real production application already has its own backend, database, Host authentication, REST APIs, WebSocket infrastructure, quiz engine, timers, scoring, leaderboard, recovery, results, security controls, and deployment infrastructure.

This Replit project is ONLY for designing and producing the frontend UI that may later be selectively integrated into that existing application.

DO NOT create or integrate:

Use React + TypeScript + Vite principles.

Use reusable components.

Mock/demo data is allowed only for visual preview and must remain clearly isolated from production-style components.
